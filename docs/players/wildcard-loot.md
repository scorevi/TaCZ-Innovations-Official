# Wildcard Loot for Players

Wildcard Loot adds TaCZ guns and attachments to normal structure containers. No new blocks, items, or loot tables are required.

## Where it works

- Chests, barrels, crates, and shulker boxes in structure loot tables
- Modded container tables using common chest/barrel/crate/shulker path names
- Fishing, piglin bartering, archaeology, villager gifts, and similar special tables are excluded by default

The default chance is `10%` per container loot roll, so most containers are still normal loot.

## What can drop

- A usable TaCZ gun with zero to six attachments
- Spare magazines for that gun
- A mix of common sidearms and rarer rifles, machine guns, snipers, and launchers
- Occasionally a **Jury-Rigged** attachment build with an off-spec part locked to the gun

A bare gun is common. A fully kitted six-attachment gun is a rare find.

## Jury-Rigged guns

Jury-Rigged parts are off-whitelist attachments that stay attached to their parent gun. The part is marked in the tooltip and stays locked through reloads. The rest of the gun remains yours to customize.

Off-spec parts only roll into slots the gun can actually mount (the same slots the refit screen shows as usable), and native/integral attachments are never used as jury-rig parts — so a Jury-Rigged gun always has a part you can see.

## Practical tips

- Check every chest, but do not expect a gun every time.
- Heavier and rarer gun types are intentionally less common.
- Spare magazines matter; guns do not arrive with infinite ammo.
- If a gun looks unusual, check its attachments before scrapping it.
- Loot is generated when a container is opened, so previously opened containers are not retroactively changed.
